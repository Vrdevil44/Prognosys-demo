# Prognosys demo

Static visitor demo of Prognosys: **sample output from public NHANES data, not medical advice.**

- Live page: https://vrdevil44.github.io/Prognosys-demo/
- `data/*.json` was generated by the real (rule-based, no-AI) Prognosys pipeline from CDC NHANES 2021–2023 public lab files (`scripts/make_demo.py` in the source repo).
- No raw `.xpt` data and no personal data are included.
